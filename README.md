EduConnect is a full-stack **web and mobile Learning Management System (LMS)** that provides secure JWT authentication with password and OTP-based login. It features role-based dashboards for students and teachers, offering course management, assignments, grades, announcements, messaging, notifications, calendars, and online classes. Built with a responsive, cross-platform design, it delivers a seamless learning experience across both web and mobile devices with real-time updates and secure API integration.
